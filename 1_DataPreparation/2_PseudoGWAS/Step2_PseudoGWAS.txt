##### GWAS Array PseudoGWAS #####
# This tutorial is designed to demonstrate how to perform pseudoGWASes on SNP array data.
# A "pseudoGWAS" is an association analysis between sets of controls to find spurious associations between datasets.
# This tutorial leads you through a pseudoGWAS with 1000 Genomes data, but the automated version includes the code for performing them between batches genotyped on the same array and between arrays.
# We recommend running a pseudoGWAS against 1000 Genomes data for each project, then between projects genotyped with the same array, then between each set of merged arrays before imputation.

# In order to use this tutorial, you will need to determine a name for your project (ProjectName).

# The inputs and outputs for each step are listed.

#############################################
##### Step 0: Prepare 1000 Genomes Data #####
#############################################
# This step uses bcftools ver. 1.15.1, but versions past 1.10 should work fine.

# It's recommended to run a pseudoGWAS with each batch and 1000 Genomes.
# The 1000 Genomes data is obtainable from: https://ftp.1000genomes.ebi.ac.uk/vol1/ftp/data_collections/1000_genomes_project/release/20190312_biallelic_SNV_and_INDEL/
# The data is in VCF format and split by chromosomes.
# Download all of the chromosome vcfs and their accompanying .tbi index.

# Concat vcf files of all the chr's
#	Prepare a list of all the vcf file names to combine and put it in file_list.txt
bcftools concat -f file_list.txt -Oz > 1KG_GRCh38.20190312_all_chr_merged.vcf.gz

#Convert vcf to Plink format.
plink1.9 --vcf 1KG_GRCh38.20190312_all_chr_merged.vcf.gz --keep-allele-order --allow-no-sex --make-bed --out 1KG_GRCh38.20190312_all_chr_merged

# Set variant IDs
plink2 --bfile 1KG_GRCh38.20190312_all_chr_merged --set-all-var-ids @:#:\$r:\$a --keep-allele-order --allow-no-sex --make-bed --out 1KG_GRCh38.20190312_all_chr_merged_updated_IDs

# QC 1000 Genomes dataset. Apply genotyping rate filter of 98%, individual missingness of 98%, and minor allele frequency cutoff of 5%.
plink2 --bfile 1KG_GRCh38.20190312_all_chr_merged_updated_IDs --geno 0.02 --mind 0.02 --maf 0.05 --make-bed --out 1KG_GRCh38.20190312_all_chr_merged_updated_IDs_qc

# Subset to EUR individuals.
plink2 --bfile 1KG_GRCh38.20190312_all_chr_merged_updated_IDs_qc --keep 1KG_EUR_to_extract.txt --make-bed --out 1KG_GRCh38.20190312_all_chr_merged_updated_IDs_qc_EUR

# This dataset will be used in Step 1.

################################################################
##### Step 1: Preparation for PseudoGWAS with 1000 Genomes #####
################################################################

# Prepare the data for performing a pseudoGWAS.

# These steps will:
#	subset data to European controls
#	merge the 2 datasets
#	generate first 10 PCs for merged data

# Inputs: 1 QCed set of plink files from the previous tutorial
#	1000 Genomes data prepared as above
#	Project name
#	A file for each project with lists of European controls in each project
# Outputs: A merged set of data from each project

export NAMEBASE="YourProjectName"

# Get just EUR Controls. Note the /path/to/previousdata is the path to the output of the previous tutorial without a file extension
plink2 --bfile /path/to/previousdata --keep HapHap_EURCO.txt --make-bed --out ${NAMEBASE}_EURCO

# Get common SNPs and flips
Rscript allele_qc.R 1KG_GRCh38.20190312_all_chr_merged_updated_IDs_qc_EUR.bim ${NAMEBASE}_EURCO.bim ./ allele_qc_report.txt

plink2 --bfile 1KG_GRCh38.20190312_all_chr_merged_updated_IDs_qc_EUR --extract extractrefSnps.txt --make-bed --out 1KG_with_${NAMEBASE}_snps

plink2 --bfile 1KG_with_${NAMEBASE}_snps --set-all-var-ids @:#:\$r:\$a --output-chr chrM --make-bed --out 1KG_with_${NAMEBASE}_snps_ids

plink2 --bfile ${NAMEBASE}_EURCO --extract extractmydataSnps.txt --make-bed --out ${NAMEBASE}_with_1KG_snps

plink2 --bfile ${NAMEBASE}_with_1KG_snps --rm-dup force-first --make-bed --out ${NAMEBASE}_with_1KG_snps_dups

plink1.9 --bfile ${NAMEBASE}_with_1KG_snps_dups --flip mydataStrandFlip.txt --keep-allele-order --allow-no-sex --make-bed --out ${NAMEBASE}_with_1KG_snps_flip

plink2 --bfile ${NAMEBASE}_with_1KG_snps_flip --set-all-var-ids @:#:\$r:\$a --output-chr chrM --make-bed --out ${NAMEBASE}_with_1KG_snps_flip_ids

# Merge
plink1.9 --bfile 1KG_with_${NAMEBASE}_snps_ids --bmerge ${NAMEBASE}_with_1KG_snps_flip_ids --chr 1-22 --maf 0.01 --allow-no-sex --keep-allele-order --make-bed --out ${NAMEBASE}_1KG_merged

# The outcome is a merged set of plink files and PCs

#######################################
##### Step 2: Make phenotype file #####
#######################################

# Prepare a phenotype file for the pseudoGWAS

# These steps will:
#	calculate PCs for use in a phenotype file
#	lead through making a phenotype file

# Inputs: 1 set of merged plink files from the previous step
# Outputs: A phenotype file

# Calculate PCs
plink1.9 --bfile ${NAMEBASE}_1KG_merged  --geno 0.001 --hwe 0.005 --maf 0.1 --pca --out ${NAMEBASE}_1KG_merged_pca

# Open ${NAMEBASE}_1KG_merged.fam in Excel.
# Remove the last 4 numerical columns.
# Insert a row at the top and name the columns "FID,IID,STATUS,SEX,PC1,PC2,PC3,PC4,PC5,PC6,PC7,PC8,PC9,PC10"
# Set the STATUS column to 1 for all of your samples and 2 for all of the 1KG samples.
# Use the 1KG_sex.txt and HapMap_sex.txt files to fill in the Sex column.
# Use the ${NAMEBASE}_1KG_merged_pca.eigenvec file to add the PC data.
# Save the file as a .txt file named "${NAMEBASE}_1KG_merged_pheno.txt".

# Make the phenotype file readable by Linux.
dos2unix ${NAMEBASE}_1KG_merged_pheno.txt

################################################
##### Step 3: PseudoGWAS with 1000 Genomes #####
################################################

# Perform pseudoGWAS.

# These steps will:
#	perform a pseudoGWAS with data prepared in previous step
#	create a list of variants with pvalues < 1e-4
#	create a manhattan plot of the data
#	create a qq plot of the data

# Inputs:
#	Project name for each project
#	The merged set of plink files from Step 1
#	A phenotype file with FID, IID, STATUS, SEX, and PC1-10
#		The STATUS in the phenotype file should be 1 for one set of data and 0 for the other set, as all are controls.
# Outputs:
#	Summary statistics from the pseudoGWAS
#	A list of variants that are statistically significantly different between the datasets
#	A manhattan plot .tiff
#	A QQ plot .jpeg

# Run GWAS
plink1.9 --bfile ${NAMEBASE}_1KG_merged --logistic hide-covar --adjust --ci 0.95 --pheno ${NAMEBASE}_1KG_merged_pheno.txt --pheno-name STATUS --covar ${NAMEBASE}_1KG_merged_pheno.txt --covar-name SEX,PC1,PC2,PC3,PC4,PC5,PC6,PC7,PC8,PC9,PC10 --keep-allele-order --allow-no-sex --out ${NAMEBASE}_1KG_merged_gwas

awk '{if ($3 < 1e-4) print $2}' ${NAMEBASE}_1KG_merged_gwas.assoc.logistic.adjusted > ${NAMEBASE}.blacklist_SNPs_1KG.txt

# Make Manhattan
Rscript make_manhattan_update.R ${NAMEBASE}_1KG_merged_gwas.assoc.logistic.adjusted

# The outcome is a list of variants to exclude
